# 简历项目描述

## 推荐版本

**AI 智能磁盘分析助手｜Python、LLM、Windows 自动化**

- 将个人磁盘扫描脚本重构为模块化桌面与 CLI 工具，完成全量遍历、候选评分、Top-N 筛选和 CSV/JSON/HTML 可视化报告。
- 设计“本地保护规则—路径隐私脱敏—AI 批量建议—严格结构校验—人工确认”的安全混合流程，限制模型直接操作高风险文件。
- 使用 SQLite 实现建议缓存，并加入批量请求、429/5xx 指数退避重试、失败批次拆分和 token 统计，降低重复调用成本。
- 在清理前基于文件大小、修改时间、设备号和文件标识进行状态复核，避免扫描与执行之间文件被修改或替换。
- 构建 40 条人工标注的模拟元数据评测集，以危险误判数量为核心指标，对比本地规则、纯 AI 与安全混合方案。
- 编写 24 项单元测试，覆盖率超过 80%，使用 GitHub Actions 完成 Windows/Linux 测试、代码检查、Python 包构建和 Windows EXE 发布。
